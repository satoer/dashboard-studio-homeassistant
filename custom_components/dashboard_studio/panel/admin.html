State Caching Keeps the last known values in memory so a reload can fill the dashboard right away. Full keeps devices and events. Optimized skips events larger than 16 KB. Devices and variables only keeps devices and variables. Disabled stores nothing.
Clear State Cache Clears the in-memory cache of last known values. Forces fresh state updates on next reload.
Viewer mode only Opens the lightweight dashboard viewer instead of the editor when you use the main dashboard link. Ideal for wall tablets and kiosks.
Keep Dashboard File History When saving over an existing dashboard, the previous file is kept as a timestamped snapshot (hidden from the normal file list). Snapshots are not a full backup: export dashboards if you need copies outside Home Assistant. If you uninstall Dashboard Studio, all user dashboard files in Home Assistant are removed.
Maximum Snapshots to Keep Per dashboard, oldest snapshots are removed when this limit is exceeded (1–50).
Show Connection Warning on Disconnect Shows a friendly dashboard notice when the active data driver goes offline. It hides automatically when the connection returns.
Enable Topic Auto-Echo Automatically reflects sent topics back to the dashboard. Keeps multiple open screens perfectly in sync.
Topic Echo Echoes published topic events to connected WebSocket clients for live canvas updates.

Home Assistant Services & Calendar Markdown:
Configure formatting rules for the Calendar & RSS Markdown services. These determine how calendar events and RSS feeds are rendered in Text and Markdown widgets.
Date Format (Calendar & RSS) Used when Calendar and RSS services show dates in Markdown tables.
Calendar Week Start First day of the week for week and month grids. Monday (Europe), Sunday (Americas / Japan), Saturday (Middle East).
Event Order Order of icon token, time label, and summary in Convert iCal JSON to Markdown (week/month cells; day view keeps time in the Time column and icon + summary in Event).
Wrap Events in Color Blocks When enabled, each event is wrapped in a [block1:]…[block4:] strip (Text widget callout style). When disabled, calendar markdown uses plain text lines.
Color Block Grouping Chooses how [block1:]…[block4:] tints map to rows. By event type follows Load & Filter behaviour (timed, all-day, multi-day, recurring). By calendar source assigns a stable tint per feed (calendarId).
Calendar Source Blocks One binding per line: calendarId, space, then block 1, 2, 3, or 4. Read calendarId from the Load & Filter iCal payload. Lines starting with # are comments. When you run Convert iCal JSON to Markdown, new sources get the least-used block (ties pick the lowest number). Duplicate IDs are invalid.
Group Timed Events by Time of Day When enabled, week-style views add section labels such as Night, Morning, Afternoon, Evening (and All Day). When disabled, events are listed without those headers.
Show Icons In Calendar When disabled, calendar markdown contains no :ph-…: icon tokens and Icon Bindings are ignored.
Use Default Calendar Icon When enabled, events with no Icon Bindings match use the default icon.
Default Calendar Icon Used when no keyword matches. Phosphor icon name (with ph-). Leave empty to reserve width. Default: ph-calendar.
Icon Bindings One line per icon: full Phosphor name (with ph-), a colon, then comma-separated keywords matched against event titles (case-insensitive). Lines starting with # are comments. Example: ph-cake: birthday, bday, verjaardag. If no keyword matches, Convert iCal JSON to Markdown uses the default icon above, or :ph-spacer: when that field is empty.
