How to enable capabilities

Choose Your Editor Experience

Select how detailed you want your widget settings to be. For new creators, Basic Mode is highly recommended to get started quickly. You can switch between Basic and Advanced modes at any time from the editor without losing any of your configuration.

Choose Your Layout Mode

Select how your widgets will be positioned and how the canvas adapts to different screen sizes.

Resolution
1180 × 820

Pick a screen size for the canvas. Unlimited lets the canvas fill the window.

Important Layout Compatibility Notice
  • Fixed Resolution and Scale to Fit Screen share the same canvas layout engine. You can toggle between them instantly at any time without affecting your widget positions.
  • Responsive Columns uses a completely different column-based grid system. Switching between a fixed canvas mode and Responsive Columns later is supported, but will require you to completely rearrange and reposition your widgets.

Choose Your Theme Style

Select a visual theme for the new dashboard. You can change themes later from Theme.

Populate Your Canvas

Pick live widgets generated from your data stream. Checked widgets are added when you create the dashboard. Select nothing to start with a blank canvas.
